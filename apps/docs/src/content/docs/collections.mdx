## ContentCard

독립적으로 이해할 수 있는 콘텐츠는 `article`로 구성합니다. 카드 전체를
강제로 링크로 만들지 않고 명확한 행동 링크를 제공합니다.

```html
<div class="pf-card-grid">
  <article class="pf-content-card">
    <p class="pf-content-card__meta">01</p>
    <div class="pf-content-card__body">
      <h2 class="pf-content-card__title">항목 01</h2>
      <p class="pf-content-card__description">짧은 설명입니다.</p>
      <a class="pf-action-link" href="#item-1">확인</a>
    </div>
  </article>
</div>
```

## IndexList

순서 또는 식별 번호가 중요한 반복 항목에 사용합니다. 시각적인 번호와 실제
목록 의미를 함께 유지하기 위해 `ol`을 권장합니다.

## InlineNav

같은 깊이의 소수 항목 사이를 이동할 때 사용합니다. 현재 위치에는
`aria-current="page"`를 설정하며, 작은 화면에서는 항목을 줄바꿈하지 않고
가로 스크롤로 보존합니다.
