---
title: 토큰
description: DTCG 원본과 생성된 CSS 변수입니다.
---

토큰은 색상, 간격, 크기, 타이포그래피, 테두리, 모션의 의미 단위로
구성됩니다. 원본은 DTCG 형식이며 Style Dictionary가 CSS 변수를 만듭니다.

## 구조

- Primitive: `color.neutral.*`, `color.accent.*`, `space.*`
- Semantic: `color.surface.*`, `color.text.*`, `color.border.*`
- Role: `font.*`, `size.*`, `motion.*`

원본 토큰은 `packages/tokens/tokens/index.json`에 있으며 생성 결과는 CSS와
평면 JSON 형식으로 제공됩니다.

```css
color: var(--color-text-primary);
padding-block: var(--space-5);
transition-duration: var(--motion-duration-fast);
```
