## Content first

컴포넌트는 장식보다 제목, 설명, 상태, 행동의 관계를 먼저 드러냅니다.
불필요한 eyebrow, 가상 브랜드 문구, 시선을 빼앗는 장식 요소를 기본 API에
넣지 않습니다.

## Border-led hierarchy

큰 그림자와 과도한 surface 중첩 대신 간격, 타이포그래피, 얇은 경계선으로
계층을 만듭니다. 파란색 accent는 링크, 선택, focus처럼 상호작용 상태에
제한합니다.

## Semantic markup

스타일 클래스는 HTML 의미를 대체하지 않습니다. 행동은 `button`과 `a`를
구분하고, 반복 콘텐츠는 `ol`·`article`, 탐색은 `nav`를 사용합니다.

## Accessible states

- 모든 폼 컨트롤은 보이는 레이블과 연결합니다.
- 도움말과 오류는 `aria-describedby`로 입력 요소에 연결합니다.
- 현재 탐색 위치는 `aria-current`로 표현합니다.
- 오류와 상태는 색상만으로 구분하지 않습니다.
- 키보드 focus는 모든 상호작용 요소에서 분명하게 보입니다.

## Responsive by composition

작은 화면에서는 단순 축소보다 구조를 재배치합니다. 카드 그리드는 한 열로,
목록 행동은 본문 아래로 이동하며, 짧은 탐색 목록은 의미를 보존한 채 가로
스크롤을 허용합니다.

## Restrained motion

모션은 hover와 focus 같은 짧은 상태 피드백에만 사용합니다. 콘텐츠를 대신하는
장식 애니메이션은 제공하지 않으며 `prefers-reduced-motion`에서 전환을
제거합니다.
